現在のブランチの `main` からの全変更をレビューしてください。

## 手順

1. `git diff main...HEAD` で変更内容を取得する
2. `.claude/rules/coding.md` を読み、コーディング規約を確認する
3. 以下の観点でレビューし、カテゴリ別に結果を報告する

## レビュー観点

### 1. 規約違反
- Controller でバリデーションに Form Request を使用しているか
- 認可が Policy で行われているか（Controller に直書きしていないか）
- 変数名・メソッド名が camelCase になっているか
- リレーションが明示的に定義されているか

### 2. テスト不足
- 新規追加したコントローラー・サービス・ポリシーにテストがあるか
- 正常系・異常系のケースが網羅されているか
- データベースの変更（マイグレーション）に対応するテストがあるか

### 3. セキュリティ
- SQL インジェクションの危険がないか（生クエリの使用等）
- 認可チェックが漏れているエンドポイントがないか
- 外部入力がバリデーションなしで使われていないか
- N+1 クエリが発生していないか（パフォーマンス問題）

### 4. デバッグコード・不要なコード
- `dd()` / `dump()` / `var_dump()` / `print_r()` が残っていないか
- コメントアウトされたコードが残っていないか
- `TODO` / `FIXME` コメントが残っていないか

## 報告フォーマット

問題が見つかった場合は以下の形式で報告してください。
問題がない場合は「問題なし」と記載してください。

```
## レビュー結果

### 規約違反
- （問題点とファイル名・行番号）

### テスト不足
- （不足しているテストケース）

### セキュリティ
- （問題点とファイル名・行番号）

### デバッグコード・不要なコード
- （該当箇所とファイル名・行番号）
```
